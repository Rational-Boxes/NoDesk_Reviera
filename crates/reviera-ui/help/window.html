The window

The ribbon and the Quick Access Toolbar at the top, the Properties palette, the Project Browser and the Model Tree in docked panes, the views as tabs in the centre, and the status bar at the bottom.

The ribbon

The ribbon's tabs hold the tools in titled panels. Every tab starts with the Select panel, whose Modify button (MD) ends the running tool so you can select elements. Hovering a button shows what it does and its keyboard sequence.

Menus

The menu bar has File, Edit, View, Architecture, Annotate, Modify, Scripts, Window and Help. They run the same actions as the ribbon and show each one's shortcut. View › Orient lists the standard directions (Top, Front, South-East Isometric…). The Scripts menu is described in Scripting.

Panes

Properties

The Properties palette (PP) shows and edits:

  • the selected element: its identity (class, name, type, IDs), its own rows (for example a wall's constraints, a door's placement and size, a roof's shape and eaves) and every parameter, grouped; type rows choose, duplicate and edit its type (see Types and parameters);
  • with a tool running and nothing selected, the type the tool will place;
  • with nothing selected, the active view: its name, view range, projection and section box.

Lengths can be typed in any unit (4.5 m, 12' 6"); see Typing lengths. Each edit is one undo step.

Project Browser

The Project Browser lists the model's views (Floor Plans, Ceiling Plans, Elevations, Sections, Schedules/Quantities, 3D Views), its sheets and its levels. Double-click a view to open it. Right-click a view to Open, Rename, Duplicate or Delete it, and a level to Rename it, Change Elevation or Delete it. Views that are open are shown in bold.

Model Tree

The Model Tree (MT) shows the model's structure: project, site, building, storeys, then categories and elements, with hosted elements (doors, windows) under their hosts. Selecting an item selects its elements; double-clicking zooms to them. Its right-click menu selects, hides, isolates, ghosts, makes translucent or shows a whole branch, zooms to it or fits a section box around it.

View tabs

Each open view is a tab, with a close button. Several models can have views open at once. Drag a tab along the tab bar to reorder it, onto another group's tabs to move it there, or to an edge of the view area to tile it beside the others.

Ctrl+Tab, Ctrl+PgDnNext view
Ctrl+Shift+Tab, Ctrl+PgUpPrevious view
Ctrl+WClose the active view
Window › Tile ViewsShow every view at once
Window › Tab ViewsPut every view back in one tab group

The help is a tab too. It opens when Reviera starts (a model opened with Reviera comes in front of it); close it with its close button, and Help › Reviera Help (F1) opens it again.

Status bar

The status bar at the bottom of the window says what the running tool expects next (for example click the start point, or the risers left to place while drawing a stair), and reports the result of each action and any error.

Full screen and focus mode

View › User Interface › Full Screen (F11) fills the screen with the views alone: the menus, the ribbon, the panes and the status bar are hidden. Focus Mode (Ctrl+Shift+F11) hides them the same way but leaves the window as it is.

  • Push the pointer against the top edge: the menu bar and the ribbon come back, with an Exit Full Screen button. They go again a moment after you move back down into the view, when you click in the view, or when you start a tool from them.
  • Push it against the bottom edge: the panes you had open come back in a row along the bottom, with the status bar. Work in them as usual; click in the view (or press Esc) to put them away.
  • Nothing appears while a mouse button is held, so a drag that reaches an edge is safe.
  • F11 again, Exit Full Screen, or Esc with nothing selected and no tool running brings everything back exactly where it was.
