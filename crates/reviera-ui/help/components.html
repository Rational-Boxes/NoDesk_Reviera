Components and Component Libraries

Components are reusable objects (furniture, fittings, planting, columns, statues) kept in Component Libraries and placed into a model as many times as you like. A component can be a 3D file from almost any modelling program, so anything you can model or download can be placed.

Component Libraries

A Component Library is simply a folder of 3D files: OBJ (with its material and texture files), STL, PLY, glTF and GLB, and IFC files. One file in the folder's root, reviera-library.json, holds what the files themselves cannot: each component's name, category, units, up axis, tags and product details, and settings for each folder. The 3D files are never changed, so the same folder can be kept in git, synced, or used by other programs.

The Component Library panel (on the right; Window › Component Library, or CL) shows the libraries you have open. Pick one in the list at the top; its folders are in the tree, and the folder you pick shows its components as thumbnails.

Open…Opens a folder as a library. A folder without a manifest can become a library as it is: Reviera only adds the manifest.
New…Makes a new library in a folder you choose.
Import…Copies 3D files into the folder shown (an OBJ brings its MTL and textures, a glTF its buffers and images). You set their units, up axis and category once for all of them; a file already in the library is skipped.

The libraries you open are remembered. Reviera comes with a small sample library; its Doric column is a public-domain scan (see the library's README).

Placing components

Click a component in the panel: you pick it up, like a stamp. Its outline follows the cursor; click to place a copy, and again for each further copy, until Esc.

  • In a plan, copies go on the plan's level, snapping like other tools.
  • In a 3D view, a copy sits on the surface under the cursor (a floor, a roof, a table top), or on the ground when there is nothing there.
  • Spacebar turns the next copy by 90°. Properties set its exact rotation, mirroring and height offset.

The first copy of a library component brings it into the model as a type; later copies share it, so a hundred chairs keep their geometry once. Architecture › Component Component (CM) places again the last component, or one already in the model.

While a component is picked up, Properties shows its details from the library: change its name, category, units or up axis there and the library's manifest is updated (the file is not).

component.place

Creating components from the model

Any selection can become a component: select the elements (a desk with its chair and lamp, a bathroom's walls and fittings, a stair core), middle-click and choose Create Component… (also on the Modify tab). Name it, and it is saved into the Component Library folder shown in the panel (or, with no library open, to a file you choose).

A component made this way is just an IFC file of that piece of the model. It brings along what the selection needs: the doors and windows in its walls, their hosts, the types and the levels. Its base point (the selection's bottom centre) is its origin and its lowest level is at 0. Other IFC tools open it as a small model.

Placing it copies its elements in with new identities. Its lowest level goes on the level you click; its other levels on the levels at the same height above (made when missing). Types the model has already are reused.

component.create, component.place_fragment

Importing a single object

Architecture › Component › Import Object Import Object brings a 3D file straight into the model, without a library. The dialog shows the object's size with the units and up axis you choose, so a wrong unit is plain before it is imported; the insertion point is its bottom centre unless you choose the file's origin or a corner. The Place Component tool then starts with it.

mesh_object.inspect, mesh_object.import, mesh_object.reload

Properties of a placed component

Offset, Rotation, Mirrored, ScaleThis copy's height above its level, its turn, its mirroring and its own scale.
Type Name, CategoryThe component type's name, and its category (the IFC class it is written as; it can change while the type has no copies).
Scale (type)Scales every copy of the type.
Colour: …Each material's colour, as #rrggbb, for every copy.

Move, Copy, Rotate and Mirror work on placed components. Deleting a type deletes its copies.

mesh_object.set, mesh_object.set_type, mesh_object.types

Array along Path

Repeats a component along a line, and stays parametric: change the count, the spacing or the path, or swap the component, and every copy follows. It works the same with a plain mesh, such as a scanned column, as with anything else.

  1. Select a placed component (or pick one up in the library) and choose Modify › Array along Path Array along Path (AP).
  2. Click a wall, a grid line or a floor to follow its line or its edges, or click points to draw a path and press Enter. Properties choose a polyline, a smooth spline or an arc, and whether it is closed.
DistributionNumber of copies, a Fixed Distance, or the Maximum or Minimum Spacing.
Counts per SideWith corners, a number for each side in turn: 8, 17 puts 8 columns on each front and 17 on each flank.
CornersSpaced through the corners, a copy At every corner (the rest spaced along each side), or corners left empty.
OrientationAlong the path, fixed, or facing outward or inward.
Random Turn, Random ScaleFor planting and other natural things, for example 0 to 360 and 0.85 to 1.15. The randomness is kept: tick Reseed for a new arrangement.
ExcludedMembers left out (array.exclude_member); type 0 to bring them all back.

An array on a wall or a floor's edges follows it when it moves or changes. Unarray Unarray turns the copies into independent objects. The Greek temple sample's colonnade is one such array.

In IFC

A component type is written as its category's type class (for example IfcFurnitureType) with its mesh once, as an IfcRepresentationMap of triangulated face sets styled in its colours; each copy is an element of the category (for example IfcFurniture) whose body maps it. A path array is an IfcElementAssembly whose members are written as elements of the component's class. Other IFC tools show them all.

Not yet available: editing a component and updating its copies, placing a component as a linked group, IFC components from other tools whose geometry Reviera does not regenerate, smart folders, 3MF and OFF files, textures, plan cut outlines of components, and reducing a large mesh on import.
