Model properties and units

The model-wide settings are in one dialog: the units and number format, the building code, and the accessibility rule set. Tools use them as their defaults.

Model Properties

Manage › Settings › Model Properties (UN; also in the File menu). Model Properties

SettingWhat it does
UnitsThe display units: Metric (mm), Metric (m), Imperial (ft-in) or Imperial (decimal ft). Lengths, areas, volumes and angles are shown as the preset formats them.
Decimal symbol, Digit groupingThe symbols before the decimals and between groups of digits.
Building codeThe code tools follow by default. See below.
OccupancyWithin a dwelling unit, or Other (public, commercial, common areas), where the code asks differently of each.
Stair headroomThe model's own stair headroom, in place of the code's. Leave it empty to use the code's value, shown beside it with its clause.
Rule set (Accessibility)None (door swings only) or ADA 2010. See Clearances.

OK applies what changed. Values are always stored in SI units; the display units change only how they are shown and the unit a bare number is read in. units.get, units.set_preset, units.set_number_format, units.set_format

Typing lengths

Every length field, and the lengths typed while drawing, accept a value with a unit:

TypedRead as
1067A bare number is in the display unit (millimetres with Metric (mm)). With Imperial (ft-in), a bare number is inches.
4.5 m, 450 cm, 4500 mmMetric lengths.
12' 6", 5'-6 1/2"Feet and inches, with fractions.
42 in, 3.5 ft, 2 ydOther units by name.

units.parse reads a value as a script would; units.format shows one in the model's units.

Building code

The model follows one building code, set in Model Properties. Today the code supplies the stair headroom the Stair tool checks:

CodeStair headroom
International Residential Code (US)6 ft 8 in (2032 mm); spiral stairs 6 ft 6 in (R311.7.2, R311.7.10.1)
International Building Code (US)80 in (2032 mm); spiral stairs 78 in (1011.3)
Approved Document K (England)2.0 m (1.10)
National Building Code of Canada1950 mm within dwelling units, 2050 mm elsewhere (9.8.2.2)
National Construction Code (Australia)2.0 m above the nosing line
DIN 18065 (Germany)2.0 m clear headroom
CustomNone of its own: set the model's stair headroom.

A tool may use another code for one operation: the stair's offer to open the floors above it lists each code with its headroom. code.get, code.set
