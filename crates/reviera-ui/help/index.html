Getting started

A new modelFile › New starts from the built-in template with one level. New model
Open an IFC fileFile › Open. Several models can be open at once, each in its own tabs. Open…
DrawThe Architecture tab: walls, doors and windows, floors, ceilings, roofs, stairs (they complete themselves to the level above), railings and decks.
ViewsThe Project Browser lists plans, 3D views, sections and sheets; double-click one to open it.

Navigating

Orbit (3D)Left drag, about the point under the cursor or the selection; or Shift + middle drag.
PanMiddle or right drag.
ZoomThe wheel, about the cursor.
Standard viewsClick the Orientation Cube's faces, edges and corners; its home button returns to the home view.

Selecting and modifying

SelectClick. Ctrl+click adds, Shift+click removes.
Box selectDrag left to right for a window (entirely inside), right to left for a crossing (touching). In 3D hold Ctrl or Shift.
Quick menuMiddle-click an element: move, copy, rotate, mirror, hide, translucency, isolate, pin, delete. With two overlapping elements selected it offers the booleans (cut, intersect, union, join).
PropertiesThe Properties palette edits the selection, its type, and with nothing selected the active view.

Model settings

Manage › Model Properties holds the units, the building code (its stair headroom) and the accessibility rules. Open Model Properties

Scripting and agents

Every tool is a registered command, available to Lua scripts (Scripts menu) and to AI agents over the Model Context Protocol.
