Quick reference

A new modelFile › New (Ctrl+N) starts from the built-in template with one level. New model
Open an IFC fileFile › Open (Ctrl+O). Several models can be open at once. Open…
DrawThe Architecture tab: walls, doors, windows, floors, ceilings, roofs, rooms, stairs, railings, decks, levels and grids. See Walls to begin.
Orbit, pan, zoomLeft drag orbits a 3D view; middle or right drag pans; the wheel zooms about the cursor. See Navigating.
SelectClick; Ctrl+click adds, Shift+click removes; middle-click opens the quick modify menu. See Selecting and modifying.
KeyboardTwo-letter sequences typed in a view start tools (WA wall, DR door…). See the shortcut list.
