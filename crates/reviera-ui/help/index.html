BIM Reviera

Open-source building information modelling on IFC. Version {{VERSION}}.

BIM Reviera is an independent, original application, not a copy or clone of any existing product. An existing application was researched to establish workflows and interface conventions familiar to the industry; beyond that, Reviera's features and enhancements are its own. IFC is its native format.

Sample models

Each opens as a fresh copy, so the sample stays as shipped; use File › Save As to keep your changes. Every sample also has a step-by-step Walkthrough of building it by hand, naming the tool for each step. They are listed by the part of the application whose tools they show, as the ribbon's tabs are: Architecture, Structure (framed buildings in steel, mass timber and light wood framing, each with its analytical model, loads and combinations), Steel (connections, cuts, plates and welds), Concrete (reinforcement and precast), Systems (air, plumbing, sprinklers, fire protection, power and lighting), Analyze (loads, colour schemes and systems analyses), Sustainability (energy, loads, daylight and carbon, with a weather file), Massing & Site (masses, toposolids and site components), Annotate (dimensions, tags, notes and sheets), View (clash detection, saved views and scope boxes), Manage (global parameters, classifications, units and selection sets) and Modify (overlap resolution, arrays, parts and other editing tools).

DrawThe Architecture tab: walls, doors, windows, floors, ceilings, roofs, rooms, stairs, railings, decks, levels and grids. See Walls to begin.
Orbit, pan, zoomLeft drag orbits a 3D view; middle or right drag pans; the wheel zooms about the cursor. See Navigating.
SelectClick; Ctrl+click adds, Shift+click removes; middle-click opens the quick modify menu. See Selecting and modifying.
KeyboardTwo-letter sequences typed in a view start tools (WA wall, DR door…). See the shortcut list.
