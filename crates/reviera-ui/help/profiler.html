Performance profiler

When Reviera feels slow on a large model, the profiler shows where the time goes, live while you work, and writes a report the developers can use to make it faster.

Starting it The live window Reports for development What it records

Starting it

Manage › Settings › Performance Profiler (also on the File menu) opens the profiler's window; Start begins recording. It is off until started, and costs next to nothing while off. To record from the moment Reviera starts (for example to time opening a large file), start Reviera with the environment variable REVIERA_PROFILE=1 (and REVIERA_PROFILE_SLOW_MS=50 for another slow threshold).

The live window

Refreshed every second while it is open:

  • the viewport's frame time (mean and worst) and frames per second, the memory in use and the model's size;
  • the latest operations, each command with how long it took;
  • the hottest scopes by self time: commands, commits, geometry regeneration, scene builds, IFC open and save, the recovery store, merges, server calls and frames, with their calls, total, 95th percentile and maximum;
  • the heaviest call paths, such as command:wall.create › commit, which show where the time goes inside an operation.

An operation slower than the threshold (100 ms unless changed) is listed as slow and shown on the status bar.

Reports for development

Export Report… writes a Markdown report: the build and machine, the model's size, the hottest operations with their share of the time, the heaviest call paths, the slow operations and the counters. Attach it to an issue to describe a slowdown. Export Trace… writes the timeline as a trace file to open in Perfetto, which shows every operation per thread on a timeline. Reset clears what was recorded.

profiler.start, profiler.stop, profiler.live, profiler.report, profiler.export_report, profiler.export_trace, profiler.reset

What it records

Only the names of operations (commands by their names), counts and times. No element names, property values, file contents, paths or passwords are recorded, so a report can be shared.
