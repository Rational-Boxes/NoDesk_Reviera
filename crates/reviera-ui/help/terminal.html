Terminal and AI agents

The Terminal pane runs your shell and command-line AI agents inside Reviera. An agent started here is already connected to the model you have open: it can look at the model and change it through Reviera's own commands, as you would.

Opening a terminal

View › User Interface › Terminal (Ctrl+Shift+T) opens the pane under the views with a Shell tab. Choose a preset in the list and press Open for another tab; Close Tab ends the selected one (asking first while its program runs). The terminal is a real one: colours, full-screen programs, the mouse wheel scrolls back through 10 000 lines, Ctrl+Shift+C copies the screen and Ctrl+Shift+V pastes.

Agents

The presets start Claude Code, Gemini CLI, Qwen Code and Codex CLI, if they are installed and on your PATH (Reviera does not install them, and their logins and API keys stay theirs). Each agent tab gets its own connection to Reviera's MCP server, set up for that session only: your agent's own settings files are never changed. Ask the agent about the model ("how many doors are on level 1?") or to change it ("make the south wall 300 mm thick").

Qwen Code starts in a session folder Reviera prepares, since that is where it reads its connection settings; the other agents start in the model's folder.

In the Flatpak, terminal tabs run on your computer outside the sandbox, so the Shell is your own login shell and the agents are the ones installed on your system. They reach Reviera through flatpak run.

What an agent may do

  • An agent's changes are ordinary commands: they undo with Ctrl+Z like your own, and the views update as they happen.
  • Anything destructive (deleting, purging, overwriting) waits for you: Reviera asks "Claude Code 2 wants to run element.delete… Allow it?". No tells the agent it was refused and changes nothing.
  • The connection is private to you: a local socket only your user can open, guarded by a secret made for each tab. Closing the tab, or the agent ending, ends the connection.

Your own presets

Add presets in terminal-presets.json in Reviera's settings folder (~/.config/reviera, or %APPDATA%\Reviera): a list of objects with an id, a name, the program and its args, and how it takes MCP servers (mcp: none, json_argument with {mcp_json} in the arguments, settings_env with the variable in setting, session_folder with the settings file's path in setting, or arguments using {bridge} and {session_file}). A preset with the same id as a built-in one replaces it.
