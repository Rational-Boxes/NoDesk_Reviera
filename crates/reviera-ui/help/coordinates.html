Exact coordinates

Every tool that takes points can be sketched with the mouse or given exact coordinates. Coordinates (XY, on the Modify tab and in every sketch tab) opens a list of points to type or correct.

What it edits

WhenThe dialog showsApply
In sketch mode (floors, ceilings, decks, roofs, openings, shafts) Each curve on its own line: start; end. More points chain lines; via x, y makes an arc. Replaces the curves, so a roughly sketched line can be put exactly in place. New lines add curves. Finish the sketch finishes it too.
Sketching area, path or fabric reinforcement, or a plate's contour The points so far, one per line, in the sketch's own plane. Replaces them; Finish makes the element.
With any other tool running (walls, beams, columns, grids, lines, railings, stairs, measuring, …) An empty list. Hands the points to the tool one by one, exactly as clicks; the option presses Enter afterwards.
With one wall, beam, grid, plate or reinforcement system selected Its ends, contour, boundary or path. Changes it in one undoable step.

Typing points

  • x, y: absolute, in project units (unit suffixes such as m or ' are accepted).
  • @dx, dy: from the point before (for the first point given to a tool, its last clicked point).
  • @distance<angle or <distance<angle: polar from the point before, the angle in degrees counter-clockwise from the x axis.

Plan tools use plan x, y. Reinforcement sketches use the host's plane (plan x, y for floors; along the wall and up from its base for walls), and plates use their face's or work plane's own axes.
