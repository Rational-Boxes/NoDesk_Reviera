Structural analysis and results

Reviera analyses the analytical model with its built-in linear static 3D frame solver, out of process, and shows the results in the model's views.

Running an analysis

Run Analysis first runs the checks: if they find errors (a part with no support, no supports at all) it asks whether to run anyway or review them. The analysis runs in the background; when it finishes its results are kept with the model and a summary per case and combination is shown (largest moment, displacement and the vertical reactions). The results go stale when the model changes. Results shows the summary again.

The built-in solver analyses members (panels are passed on to providers that analyse surfaces; their area loads are carried to the members). structural_analysis.export_model writes the neutral model (reviera-structural-model.json) for other programs.

Results Explorer

Results Explorer shows, in the 3D view, one load case or combination's:

  • member force diagrams: N, Vy, Vz, T, My, Mz, drawn off each member on the tension side, positive blue and negative red, with values;
  • the deformed shape, including each span's sag between its supports;
  • the reactions, as arrows at the supports.

Choose all members, columns, beams, braces or transfer beams, a scale, and the deformed shape under a force diagram. Presets (column axial forces, support reactions, beam moments with deformation …) set it all at once; Save Preset… keeps your own. Insights lists the largest values: click one to select its member and frame it. Opaque elements hide results behind them: use Hide/Isolate or a section box.

Managing results

Export… writes the result set as a .reviera-results package and Import… reads one back (results from another state of the model show as stale); Delete removes it. results.*, structural_analysis.import_results

Not yet available: panel stresses and moments, modal and other analysis types, external providers (PyNite, CalculiX, xara), results in plans and sections.
