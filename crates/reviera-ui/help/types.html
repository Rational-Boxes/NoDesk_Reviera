Types and parameters

Most elements have a type that holds the values they share, such as a wall's width or a door's size. Each element also has its own parameters. Both are edited in the Properties palette and saved as ordinary IFC types and property sets.

Types

Walls, doors, windows, floors, ceilings, roofs, stairs, railings and grids have types. In Properties, the Type row of a selected wall, door, window, floor, roof or grid shows its type:

  • Choose another type from the list to change the selected elements' type.
  • Duplicate Type… (the last entry in the list) copies the current type under a new name and gives it to the selection. Change the new type's values afterwards.
  • Type Name renames the type.
  • The rows under Type Parameters (n walls) are the type's values. Changing one changes every element of that type: the heading says how many there are.

With a tool running and nothing selected, the Type row chooses the type the tool places: start the Wall, Door, Window or Grid tool, then pick the type in Properties before clicking in the view.

To make a new door type

  1. Place a door (the first door makes the default type) and select it.
  2. In Properties › Type, choose Duplicate Type… and type a name, for example Arched Door 1000 x 2400.
  3. Under Type Parameters, set Width 1000, Height 2400 and Shape Round Top.

The Manor and Storefront samples are built from types made this way. type.list, type.duplicate, type.rename, type.set_param, element.set_type

Instance and type parameters

Properties list every parameter of the selection, grouped (Identity Data, Constraints, Dimensions and so on). Type parameters are marked as such; editing one changes the type. An instance parameter belongs to the selected element alone. When several elements are selected, an edit applies to all of them.

Some values are computed and read-only, such as a floor's area and volume or a stair's actual riser height; they are shown greyed.

Parameters are written to IFC property sets, so other IFC tools see them. param.list, param.get, param.set, param.set_many, param.clear, param.definition

Project parameters and property sets

Project parameters (your own parameters, bound to categories as type or instance parameters) and direct property set edits are available as commands today; there is no dialog for them yet. Run them from the command shell or a script: param.project.add, param.project.modify, param.project.remove, param.set_ifc_home, pset.set, pset.remove. Once added, a project parameter shows in Properties like any other.
