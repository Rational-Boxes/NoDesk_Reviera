Getting started

Reviera works directly on IFC files: there is no separate project format. This page covers creating, opening, saving and closing models, and getting work back after a crash.

Starting a model

File › New (Ctrl+N) creates a model from the built-in template. It has one level, Level 1, at elevation 0. New model

To start drawing:

  1. Open the Level 1 floor plan: double-click it under Floor Plans in the Project Browser, or create it with View › Floor Plan.
  2. Choose a tool on the Architecture tab, for example Wall (WA). See Walls.
  3. Add more levels with Architecture › Level (LL). See Levels and grids.

Opening a model

File › Open (Ctrl+O) opens an IFC file (IFC2X3, IFC4 or IFC4X3_ADD2). Large files load in the background: a tab shows the progress while the file is read and its geometry is built. Open…

  • Elements Reviera does not model itself (furniture, equipment, imported stairs) are kept, drawn and can be selected. Saving keeps them as they were.
  • A file that is already open in another Reviera session opens read-only.
  • From a terminal, reviera gui model.ifc starts the window with a file open.

Several models

Several models can be open at once. Each model's views are tabs in the centre of the window; the active tab decides which model the ribbon, the Project Browser and Properties work on. File › Close Model (Ctrl+Shift+W) closes the active model and all its views, and asks to save changes first. Window › Close View (Ctrl+W) closes just the active view.

Saving

File › Save Ctrl+SSaves the model to its IFC file.
File › Save As Ctrl+Shift+SSaves the model to a new IFC file.

Reviera's own elements are written as ordinary IFC entities (IfcWall, IfcSlab, IfcDoor…), so other IFC tools read them. What Reviera needs to edit them again (sketches, recipes, views, settings) goes into Reviera_* property sets in the same file. Views, schedules and sheets are saved in the file too.

After a crash

Every change is also written, encrypted, to a local live store as you work. If Reviera ends unexpectedly, the unsaved work and its undo history can be recovered:

  1. Open the same file again with File › Open.
  2. Reviera says the file has unsaved work from a session that ended unexpectedly and asks whether to restore it.
  3. Yes restores the work; No discards it and opens the file as saved.

Running reviera with no arguments in a terminal lists the unsaved work that is waiting; the commands recovery.list, recovery.restore, recovery.show_changes and recovery.discard manage it from the command shell.

Closing Reviera

File › Exit closes every model and the window.
