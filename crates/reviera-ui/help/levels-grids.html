Levels and grids

Levels are the storeys of the building: walls, floors and rooms sit on them and stairs climb between them. Grids are the lines that set out the structure.

Levels

To add a level

  1. Architecture › Datum › Level (LL). Level
  2. Type the new level's elevation. The suggestion is one storey above the top level; any unit can be typed (3000, 3 m, 10').
  3. OK. The level is named after the one below (Level 2 after Level 1) and gets its floor plan.

Changing a level

  • Select a level in the Levels group of the Project Browser: Properties show its Name and Elevation to edit.
  • Right-click it in the Project Browser for Rename…, Change Elevation… and Delete.
  • Moving a level moves the walls on it, and stretches the walls that rise to it. Stairs keep reaching the level above.
  • Deleting a level first lists what would be deleted with it (its views, the elements on it).

Levels are saved as IfcBuildingStorey. level.create, level.set_elevation, level.rename, level.list

Grids

To draw grid lines

  1. Open a plan. Architecture › Datum › Grid (GR). Grid
  2. Optionally choose the grid type in Properties before clicking.
  3. Click the start and the end of the line. Points snap to the ends and midpoints of grids and walls, to cut edges, and to 15° directions from the start. The preview shows the bubble and the name the line will get.
  4. Draw more lines. Esc drops a start point; again, it ends the tool.

Names continue the series: 1, 2, 3… or A, B, C…. Rename a grid with its Name in Properties.

Grids in the model

  • Grids show in every plan, and in sections and elevations, with their bubbles, and in PDF.
  • A selected grid shows a grip at each end to drag; the Modify tools (Move, Copy, Offset) work on grids.
  • Dimensions to grids follow them when they move.
  • Grid types set the Symbol (Bubble or None), Bubble at Start and Bubble at End, the Center Segment (Continuous, None or Custom, with the End Segments Length on paper), and the pens and patterns.

All grid lines are saved as one IfcGrid, with an IfcGridAxis per line; axes changed in another IFC tool are taken over when the file is opened. grid.create, grid.rename, grid.set_curve, grid.list

Datum extents

A level, grid or reference plane has its 3D extent, the same in every view: a grid's line, and in sections and elevations its heights. A view can give it a 2D extent of its own. Select the datum and set Extent in View to 2D in Properties; dragging its ends then changes this view only. 3D drags change it everywhere.

  • Bubble at Start and Bubble at End show or hide a grid's bubbles in this view; Elbow at Start and Elbow at End jog a grid's line near its bubble, to clear crowded bubbles.
  • Modify | Grids › Reset to 3D Extents removes the 2D extent in this view; Maximize 3D Extents stretches grids and reference planes over the whole model; Propagate Extents copies this view's extents to other plans (or to parallel sections and elevations).
  • In sections and elevations a level's extent is its ends across the view.

datum.set_extent, datum.reset_to_3d, datum.maximize_3d, datum.propagate_extents, datum.set_bubble, datum.add_elbow, datum.get

Scope boxes

A scope box is a named box that limits where datums show. View › Create › Scope Box Scope Box draws one in a plan: click two opposite corners. It reaches from below the lowest level to above the highest; set its Height, Rotation and Name in Properties.

Choose a datum's Scope Box in its Properties: it then shows only in the views that cross the box, and a grid's or reference plane's line is clipped to the box's footprint. Moving, turning or resizing the box carries them with it. Clearing the box keeps the datum's extent. A plan's, section's or elevation's Scope Box (Properties › Extents) crops the view to the box (see Crop regions). Saved as an IfcAnnotation (ObjectType ScopeBox) with an IfcBoundingBox.

scopebox.create, scopebox.set_extents, scopebox.list, datum.assign_scope_box, view.assign_scope_box

Reference planes

A reference plane is an unbounded construction plane: a guide to align and dimension to, and a plane to draw on. Architecture › Datum & Work Plane › Ref Plane Ref Plane (RP) draws one in a plan: click the two ends of its line. The plane is vertical, through the line. Give it a Name in Properties (while the tool runs, or afterwards) to offer it as a work plane; names are unique.

  • Plans show reference planes as dashed green lines; sections and elevations show the ones they look along. 3D views do not show them.
  • Move, Copy, Rotate and Mirror work on them; model lines drawn on a plane follow it.
  • Saved as an IfcAnnotation (ObjectType ReferencePlane) whose Axis is the line.

refplane.create, refplane.rename, refplane.set, refplane.list

Work planes

Every view has a work plane, the plane model lines are drawn on. A plan's is its level until you set another. Datum & Work Plane › Set Set chooses one by name: a level, a grid or a named reference plane. Show Show draws it as a grid in the view.

An element on a work plane keeps its place in that plane: raise the level or move the reference plane, and it moves with it. Moving the element alone in plan keeps it on a plane fixed where it now is.

workplane.set, workplane.get, workplane.show, workplane.list, element.set_work_plane, element.dissociate_work_plane

Model lines

Model lines are lines in the model, shown in every view, unlike a view's own annotation. Datum & Work Plane › Model Line Model Line (LI) draws on the plan's work plane: click the start, then the end. With Chain on, each line starts where the last ended; Shape Arc takes a third click on the arc. Esc ends the chain, then the tool. Choose a Line Style (Lines, Thin, Medium or Wide Lines, Hidden, Centre or Overhead Lines) in Properties, for new lines or the selected ones.

Plans show the model lines within their view range, sections and elevations those within their depth, and 3D views all of them. Each is saved as an IfcAnnotation (ObjectType ModelLine) whose curve is styled with its line style.

modelline.create, modelline.set, modelline.list, modelline.styles
