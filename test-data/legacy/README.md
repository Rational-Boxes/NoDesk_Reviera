# Files written under the old spelling

`reviera_named_stairlifts.ifc` is the *Stairlifts* sample as saved before the project's name was
corrected from "Reviera" to "Riviera" (2026-11-04). Its own property sets are still named
`Reviera_Element`, `Reviera_Type`, `Reviera_Manifest` and `Reviera_Stairlift`, with the format
`reviera-rxd`. The test `legacy_names` opens it to check that files saved under the old spelling
keep their Riviera data. These files are left out of the rename.
