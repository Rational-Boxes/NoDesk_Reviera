## 1. Purpose

This log confirms that **every piece of information in the Reviera design documents comes from publicly available sources**. No proprietary, confidential, leaked, NDA-covered or otherwise non-public information was used.

For each fact in the specification, the log records:
- **where** it came from: a public URL in the Source Register (§5)
- **when** it was retrieved, and **how**: a dated session entry (§4)
- **who** saw which material (§7)

So anyone can trace a statement in the specification back to a public source and check that the source was openly available on the date it was used.

The specification is functional. It describes *what* the reference application does from the user's point of view, in our own words.

**Independence.** BIM Reviera is an independent, original application. It is in no way a copy or clone of any existing product, and it does not set out to read or write any existing product's closed, proprietary formats (such as RVT and RFA); IFC is its native format. An existing application was researched, from public sources only, to establish the workflows and user-interface conventions that the industry's users already know, so they can work in Reviera without relearning their trade. Beyond that research, Reviera implements its own features and enhancements: its architecture, native IFC storage, scripting and AI integration, remote computation and analysis, and many of its modelling tools are its own design. Interchange formats used across the industry, such as DWG and DXF, are supported only through open-source libraries, for interoperability. This log covers the research; the features and enhancements that go beyond it are recorded here too, as Reviera-originated entries that cite no reference-product sources.

## 2. Clean-Room Protocol

| # | Rule | Status |
|---|------|--------|
| P1 | Use only publicly accessible sources: vendor help docs, public blogs, published tutorials, public forums, press and release notes. | In force |
| P2 | No decompiling, disassembling, debugging or reverse-engineering of Revit binaries, file formats or network traffic. | In force |
| P3 | No installing or running Revit, and no use of a Revit licence, for this research (this avoids taking on EULA obligations). | In force |
| P4 | No confidential, leaked, NDA-covered or paywalled-and-redistributed material. No current or former Autodesk employee's non-public knowledge. | In force |
| P5 | No copying of Autodesk source code, API implementation code, icons, artwork, fonts, family/template content (.rfa/.rte/.rft) or help text into Reviera deliverables. | In force |
| P6 | The specification describes behaviour and functional requirements in our own words. Short quotations are kept to a minimum and attributed. | In force |
| P7 | Screenshots are kept as **internal reference only**, with a recorded source URL. They are not to be shipped, redistributed, or traced or copied into Reviera's UI assets (see §6). | In force |
| P8 | Every research session gets a dated entry in §4. Every source gets an entry in §5. | In force |
| P9 | Recommended: people who implement Reviera work from the specification, not from the raw screenshots or vendor docs. Any exposure to those should be noted in §7. | Recommended |

**Public-availability test for a source.** A source qualifies only if all of these are true:
- anyone could reach it without logging in, or with only a free public account
- it was not behind an NDA, beta programme, partner portal or employee-only system
- it was not leaked, scraped from a private system, or redistributed without authorisation

Any source that fails this test is rejected. Rejections are noted in the session entry.
